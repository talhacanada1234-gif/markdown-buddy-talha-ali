# Reflection

## 1. How did AI support the documentation process?

AI supported the documentation process by suggesting a logical README structure, improving wording, and recommending Markdown formatting such as headings, bullet lists, and code blocks. This made it easier to organize the R project documentation in a professional and readable way.

## 2. What are the strengths and weaknesses of AI-assisted documentation?

A major strength is that AI can quickly suggest structure and provide formatting ideas. It can also help identify unclear wording and make documentation more consistent. A weakness is that AI-generated content still needs human review. It may include assumptions, inaccurate statements, or formatting that does not match the actual project. For this reason, the final documentation must be checked manually.

## 3. How did you verify and improve the AI output?

I reviewed the generated Markdown for headings, lists, code fences, and overall readability. I also checked the R Markdown organization and ensured that the code examples use synthetic data. The final files should be previewed in GitHub and knitted or previewed in RStudio/Posit Cloud before submission.
